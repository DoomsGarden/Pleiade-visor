# Visor público de Pléiade

GitHub Pages despliega `dist/` de una versión publicada en el repositorio del motor. El flujo **Publicar visor en GitHub Pages** comprueba las nuevas versiones cada hora y guarda la versión y su publicación en el resumen de Actions.

Para sincronizar de inmediato, ejecuta el flujo en `main`. El campo **release** permite seleccionar una etiqueta publicada. [Versiones del motor](https://github.com/DoomsGarden/Pleiade/releases)

[Ver Pléiade](https://doomsgarden.github.io/Pleiade-visor/)
